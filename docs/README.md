# Documentación de Ramax Café Club

## Orden de consulta

1. [MVP funcional](./RAMAX_CAFE_CLUB_MVP.md) define alcance, reglas de negocio y criterios de aceptación.
2. [Plan de desarrollo](./PLAN_DESARROLLO_INCREMENTAL.md) define arquitectura, módulos, API, pruebas y orden de entregas.
3. [Backlog E1](./BACKLOG_E1_OPERACION_LOCAL.md) convierte la operación local en historias, tareas y criterios verificables.
4. [Revisión de importación](./IMPORTACION_LIBREOFFICE.md) define qué hojas entran al contrato de LibreOffice y cuáles quedan fuera del MVP.
5. [Decisiones de arquitectura](./adr/) registra elecciones técnicas difíciles de revertir.
6. [Glosario del dominio](../CONTEXT.md) define los términos usados por los demás documentos.

Si dos documentos discrepan, el MVP manda sobre reglas de negocio y el plan manda sobre implementación. Un cambio que afecte ambos debe actualizar los dos en la misma entrega.
